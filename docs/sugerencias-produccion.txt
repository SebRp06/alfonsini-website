======================================================================
1. HOSTING DEL SITIO (Next.js)
======================================================================
Gratis / bajo costo
  - Vercel (plan Hobby): despliegue directo de Next.js, CDN global, ISR. El plan gratuito
    es para uso no comercial: para una tienda real conviene el plan Pro.
  - Cloudflare Pages + Workers (adaptador OpenNext): plan gratuito generoso, CDN en Bogotá.
  - Netlify (plan gratuito): sencillo; Next.js soportado con su runtime.
De pago
  - Vercel Pro: lo más simple para el equipo; analítica de Web Vitals incluida.
  - AWS Amplify / Fly.io / Railway / un VPS (DigitalOcean, Hetzner) con Docker: más control,
    más mantenimiento.
Recomendación AccedIT: Vercel Pro o Cloudflare (ambos con CDN y cabeceras de seguridad).

======================================================================
2. BASE DE DATOS (catálogo, pedidos, lista de espera)
======================================================================
Gratis para empezar
  - Supabase (Postgres + almacenamiento de fotos + autenticación lista para el futuro módulo
    de usuarios). Plan gratuito con límites y pausa por inactividad.
  - Neon (Postgres serverless): plan gratuito, ramas de BD para pruebas.
  - Turso (SQLite distribuido) o Cloudflare D1: muy baratos para catálogos pequeños.
De pago
  - Supabase Pro / Neon pago: copias de seguridad diarias, sin pausas.
  - Postgres administrado (AWS RDS, Google Cloud SQL, DigitalOcean): más costo, más control.
Recomendación AccedIT: Postgres (Supabase o Neon) + ORM tipado (Drizzle o Prisma).
Tablas mínimas: productos, variantes(talla, sku, stock), imagenes, categorias, pedidos,
lineas_pedido, reservas_stock, lista_espera, consentimientos (Ley 1581).

======================================================================
3. GESTIÓN DE STOCK / INVENTARIO
======================================================================
Opción A · Propio (gratis en licencias)
  - Tabla de variantes por talla con stock y reserva temporal (15 min) al confirmar pedido;
    liberación automática si no se paga (Bre-B) en el plazo.
  - Panel administrativo sencillo (Next.js + autenticación del equipo) o Supabase Studio.
Opción B · Integrar con lo que ya use Alfonsini
  - Si facturan con Siigo, Alegra o World Office: sincronizar stock por API (de pago, según plan).
  - Hoja de cálculo como fuente temporal (Google Sheets API): rápido, frágil a escala.
Opción C · Plataforma de comercio "headless" (de pago)
  - Shopify (Storefront API), Medusa (código abierto, autohospedado gratis) o Saleor:
    traen inventario, pedidos y panel. Medusa es la opción abierta más alineada al core agnóstico.
Recomendación AccedIT: A si el catálogo es < 300 referencias; Medusa si crecerá a mayoristas.
